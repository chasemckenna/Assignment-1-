# Assignment-1 - Chase McKenna

## Exercise 1: Profit Margin Calculator

This exercise asks the user for revenue and cost, then calculates profit and profit margin. It also checks that revenue is valid before dividing so the program does not break. The final output is written in a clear business-style format with dollar and percentage values, which makes it a great first practice with floats and formatting.

## Exercise 2: Credit Score Evaluator

This exercise uses conditional statements to decide whether a customer qualifies for a loan based on their credit score. It checks for valid score ranges and prints different messages depending on whether the score is excellent, good, fair, or poor. This is a straightforward way to practice if/elif/else logic in a realistic financial example.

## Exercise 3: Customer Greeting Formatter

This exercise focuses on cleaning and formatting names for a customer greeting. The program takes a full name, removes extra spaces, capitalizes it correctly, and uses the first name in the final message. It also handles blank input by returning a default greeting. This is a good introduction to string methods like `strip()`, `title()`, and `split()`.

## Exercise 4: Tax Bracket Determiner

This exercise uses functions to determine a person's tax bracket based on income. It checks if the income is valid, assigns the correct bracket, and calculates the estimated tax using the rate for that bracket. It is a practical example of how functions can return values and how decision-making logic can be reused in code.

## Exercise 5: Product Category Matcher

This exercise uses a match-case statement to sort products into categories like electronics, clothing, and food. The program cleans the product name by trimming whitespace and converting it to lowercase before matching it. This helps show how Python can handle different user inputs more reliably and makes the logic easier to read.

## Bonus Challenge: Integrated Decision Tool

This bonus exercise brings together several ideas from the earlier tasks into one business decision tool. It asks for revenue, cost, and category, checks whether the business is profitable, and then recommends an action based on the category. It is a nice final project that combines functions, conditionals, and match-case logic in one example.

## Assumptions

These exercises assume Python 3.x is being used in VS Code and that inputs are entered manually in the terminal. The goal is to practice beginner programming concepts in a realistic way.
